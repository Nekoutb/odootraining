Supprimer ou archiver un enregistrement

À faire

Objectif. Retirer une fiche devenue inutile sans perdre l'historique comptable.

Où dans Odoo 15Liste concernée › cocher la ligne › Action › Archiver ou Supprimer

Ce que vous faites

  1. Dans la liste, cochez la ligne concernée (1).
  2. Ouvrez le menu Action (2).
  3. Choisissez Archiver (3) pour masquer la fiche sans l'effacer : c'est le choix normal pour un client, un fournisseur, un article ou un journal.
  4. Supprimer (4) n'est possible que si la fiche n'a jamais été utilisée. Odoo refuse sinon.

À vérifier avant de continuer

0 / 2
À éviter.
  • Ne supprimez jamais une facture comptabilisée : faites un avoir.
  • Ne supprimez pas un tiers pour le recréer : corrigez sa fiche.

Exercice sur la base de test

Archivez un client de test, retrouvez-le avec le filtre Archivé, puis désarchivez-le.
