Paramétrer le valideur des écritures

Objectif. Faire approuver les opérations diverses par une seconde personne.

Où dans Odoo 15Paramètres › Technique › Validation par un tiers › Tier Definition (mode développeur)

Ce que vous faites

  1. Activez le mode développeur (Paramètres, en bas de page).
  2. Créez une règle : modèle (1) Pièce comptable, type (2) Individuel.
  3. Valideur (3) : le chef comptable.
  4. Domaine (4) : les écritures du journal des opérations diverses.

À vérifier avant de continuer

0 / 1
À éviter.
  • Le saisisseur ne doit pas être son propre valideur.

Exercice sur la base de test

Consultez la règle de validation et notez le valideur.
