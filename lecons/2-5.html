  5. 2.5Plan comptable : créer, renommer, archiver un compte

Objectif. Faire évoluer le plan comptable SYSCOHADA sans casser l'historique.

Où dans Odoo 15Facturation › Configuration › Comptabilité › Plan comptable

Ce que vous faites

  1. Recherchez d'abord le numéro (1) : le compte existe peut-être déjà.
  2. Cliquez sur Créer (2) : numéro à 6 chiffres, intitulé, type (créances, dettes, charges…).
  3. Pour renommer, ouvrez le compte (3) et changez l'intitulé ; le numéro ne change pas.
  4. Un compte inutile se désactive (Action › Archiver) ; il ne se supprime pas s'il porte des écritures.

À vérifier avant de continuer

0 / 2
À éviter.
  • Ne créez pas de compte d'attente sans règle pour le solder.

Exercice sur la base de test

Créez le compte 604710 Fournitures informatiques, type Charges.
