Leçon 5.2 · 15 min

Créer et paramétrer un journal

À faire

Phase 5 · leçons

  1. 5.1Comprendre les journaux
  2. 5.2Créer et paramétrer un journal
  3. 5.3Archiver ou supprimer un journal

Objectif. Ouvrir un nouveau journal de banque, de caisse ou d'opérations diverses.

Où dans Odoo 15Facturation › Configuration › Comptabilité › Journaux › Créer

Ce que vous faites

  1. Cliquez sur Créer, saisissez le nom (1) : « Banque SGC 0123 » par exemple.
  2. Type (2) : Banque, Espèces, Ventes, Achats ou Divers.
  3. Onglet Pièces comptables : code court (3), 5 caractères au plus, et compte de trésorerie pour une banque ou une caisse.
  4. Sauvegardez (4).

À vérifier avant de continuer

0 / 2
À éviter.
  • Ne réutilisez pas le code d'un ancien journal.

Exercice sur la base de test

Créez le journal Caisse dépenses courantes, type Espèces.
